# Mobile app (Flutter)

No Flutter SDK is installed on this machine (by choice — no local storage for it). This folder currently has only `pubspec.yaml` and `lib/` source — the `android/` and `ios/` platform folders don't exist yet because those are generated by the Flutter tool itself, not hand-written.

## To get this running (on Codemagic or any machine with Flutter installed)

1. `flutter create .` inside this folder — generates `android/`, `ios/`, and merges with the existing `pubspec.yaml`/`lib/` (don't let it overwrite `lib/main.dart`).
2. `flutter pub get`
3. Android screenshot block: `no_screenshot` handles this at the Dart level; no extra native setup needed.
4. iOS: screen recording can only be *detected*, not blocked — `no_screenshot` hides content on detection. Tell the client this upfront.
5. Point `apiBaseUrl` in `lib/services/api_client.dart` at the deployed backend (Vercel URL) before any real build.
6. Codemagic: add this repo, point it at `mobile/` as the project root, use the default Flutter workflow — it'll produce an installable APK/IPA without needing Flutter locally.

## What's wired up

- `lib/services/device_id.dart` — per-install device id sent on every login for single-device enforcement.
- `lib/services/api_client.dart` — talks to the Next.js backend: login, signup, courses, lessons, video-url, Razorpay create-order/verify. Stores the JWT in secure storage.
- `lib/screens/login_screen.dart`, `signup_screen.dart`, `course_list_screen.dart` — login/signup + browse flow.
- `lib/screens/course_detail_screen.dart` — Razorpay checkout (`razorpay_flutter`): buy → native checkout UI → backend verifies the signature server-side before enrolling. The app never trusts its own "payment succeeded" callback alone.
- `lib/screens/lesson_list_screen.dart`, `video_player_screen.dart` — enrolled students see lessons and stream video via a fresh signed URL fetched right before playback (not cached — it expires in ~1 hour).
- `main.dart` — `no_screenshot` turns screenshot/recording block on at app start.
